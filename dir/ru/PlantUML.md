
# Визуализация модели (PlantUML)

Для наглядного представления структуры данных в проекте используется **PlantUML**. Это позволяет автоматически генерировать графические UML-диаграммы из текстовых описаний.

---

## 1. Установка и генерация
Чтобы преобразовать текстовый файл `domain.puml` в изображение, выполните следующие шаги:

### Установка PlantUML (macOS):
```bash
brew install plantuml
```

### Генерация диаграммы:
Перейдите в корень репозитория и запустите команду:
```bash
plantuml artifacts/domain.puml
```

### Результат:
В папке `artifacts/` появится графический файл:
*   `artifacts/domain.png` (или `.svg`)

---

## 2. Представление в документации
В рамках научной работы или для отображения в GitHub README сгенерированную диаграмму можно вставить следующим образом:

![Domain Diagram](artifacts/domain.png)

---

## 3. Роль в проекте
На текущем этапе (Version 1) диаграммы PlantUML выполняют роль **документационного артефакта** (documentation artifact). Они служат для визуальной верификации структуры, описанной в `model.yaml`.

**Научное обоснование:**
> *The domain model is additionally represented using PlantUML diagrams to provide a visual UML-based representation of the project artifacts.*

В будущих версиях (Version 7) планируется переход к использованию UML-схем как прямого источника для генерации кода (XMI -> Generator), что обеспечит полную интеграцию с профессиональными CASE-средствами.
